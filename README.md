# 愛馬くん（蒼天ダービー）

ブラウザで遊べる競走馬育成・ジョッキーゲームです。
愛馬を育成してレースに挑み、最終目標「蒼天ダービー」の優勝を目指します。

## 遊び方

1. ゲームを開き、画面の案内に従って愛馬を育成します。
2. レースでは画面に表示される操作を使って騎乗します。
3. 育成とレースを重ね、蒼天ダービーの優勝を目指しましょう。

※ 操作方法や各機能の詳細はゲーム内の表示を確認してください。

## ゲームの特徴

- 愛馬の育成とレース
- レース中のムチ操作とスタミナ管理
- 最終レース「蒼天ダービー」
- 優勝馬の記録を振り返る「名馬一覧」

## 起動方法

`index.html` をブラウザで開いてください。GitHub Pagesに公開する場合は、リポジトリの公開対象フォルダに `index.html` を置きます。

## セーブデータについて

ゲームの保存機能はブラウザ側のデータを使用します。ブラウザのデータ削除や端末・ブラウザの変更により、記録が引き継がれない場合があります。
